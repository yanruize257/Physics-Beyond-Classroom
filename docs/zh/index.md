# Physics Beyond Classroom

Physics Beyond Classroom 是一个由高中生编写的物理网站，关注电磁辐射及其与物质的相互作用。

网站源自三段科研经历：氢原子频率基准、半导体光谱和伽马射线天文学。每个项目都有自己的论文或报告，但过程中我还接触到许多没有写进最终成果的有趣物理。我希望把它们理解得更清楚、并有序地保留下来，于是汇集在这里。

文章从高中物理出发，逐步走向科研中真实的仪器与方法，配有直观解释、示意图和必要的推导。三个主题按电磁频谱的波段组织——微波、可见光与紫外、伽马射线。它们是不同的问题；频谱只是组织它们的一种自然方式。
