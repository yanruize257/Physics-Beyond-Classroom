# 波函数与量子态

*本页介绍波函数与玻恩规则，并把它们与原子的量子数联系起来。*

## 1. 物质波

德布罗意（1924）：动量为 \(p\) 的粒子携带波长

\[
\lambda = \frac{h}{p},
\tag{1}
\]

其中 \(h\) 是普朗克常数。1927 年得到证实——电子打在晶体上产生与 X 射线一模一样的衍射图样（Davisson–Germer）；今天的电子显微镜就靠它工作。一个 \(1\ \mathrm{kg}\) 的小球以 \(1\ \mathrm{m/s}\) 运动，\(\lambda = h/mv \approx 6.6\times10^{-34}\ \mathrm{m}\)——不可察觉。而原子内的电子 \(\lambda \approx 10^{-10}\ \mathrm{m}\)，正是原子自身的尺寸：它必须装得下。

## 2. 波函数 \(\psi\)

粒子的波写作 \(\psi\)，称为**波函数**。玻恩规则：\(|\psi(x)|^2\) 是在 \(x\) 处找到粒子的概率密度——波高的地方，粒子就容易出现。概率在全空间加起来必须等于一：

\[
\int |\psi|^2\, dx = 1.
\tag{2}
\]

有一处记号值得用图像而不是代数来理解。\(\psi\) 可以是复数值，而 \(|\psi|^2 = \psi^*\psi\)——波"长度的平方"，就像影子的长度平方才要紧，影子朝哪边指无所谓。把 \(\psi\) 想象成一根旋转的箭头：箭头的方向携带波的相位——整体相位不可观测，但路径之间的相对相位会体现在干涉里——只有它的*长度*的平方变成概率。真实可测的物理量永远是 \(|\psi|^2\)。

## 3. 波必须装得下

上一页的教训在这里变成一条物理原理。被囚禁的波——就像固定琴弦上的驻波图案（[1.2 页](interference-standing-waves-and-quantization.md)）——不能有任意形状；只有某些图案装得下。允许的图案组成一个*离散*的集合——图案 1、图案 2、图案 3，两者之间什么都没有——因为波要么装得下，要么装不下。

把同一个想法搬进原子核周围的三维空间，就得到原子的离散状态。原子核周围"装得下"的方式更丰富，存活下来的图案由量子数标记：\(n\)（主量子数）与图案的能量和尺度相关，\(l\) 与轨道角动量相关，\(m\) 是该角动量沿选定轴的投影。关键不是这些标签，而是它们的来源：离散性来自"装得下"，而不是来自什么隐藏规则。严格地说，氢的能级来自原子核库仑势中的量子本征态；"装得下"的图像抓住了离散性，但只是类比，不是推导。（一个必须小心的区分："离散"指状态彼此分开、之间没有别的状态——它*不*意味着数量有限。例如氢就有一条无穷的阶梯，\(n = 1, 2, 3, \dots\)。）

## 4. 原子能级

真实的原子通过原子核的库仑吸引束缚电子，它装得下的图案就是它的能级。氢的阶梯是

\[
E_n = -\frac{13.6\ \mathrm{eV}}{n^2},
\tag{3}
\]

\(n = 1, 2, 3, \dots\) 就是 K、L、M 壳层——这是量子力学的标准结果，这里引用而不推导。基态 \(E_1\) 是最低的阶梯，其上每级都是激发态；同一元素的每个原子，在任何地方，都拥有同一个阶梯——一个写进自然的频率基准，与受制于环境的摆形成对照。

**跃迁**是波从一个图案切换到另一个图案：原子从 \(E_2\) 落到 \(E_1\)，能量差以一个光子的形式离开，

\[
E_2 - E_1 = h\nu,
\qquad
\boxed{\nu = \frac{E_2 - E_1}{h}}
\tag{4}
\]

其中 \(h = 6.626\,070\,15\times10^{-34}\ \mathrm{J\cdot s}\)（2019 年起为精确值）。因为能级间距和 \(h\) 都是普适常数，光子的频率固定，且对同种元素的每个原子完全相同——一个没有任何部件可磨损的振荡器。逆过程是吸收：当 \(h\nu\) 与能级间距匹配时吸收最强——真实的谱线有有限宽度，来自能级的自然寿命和原子的运动——这正是每种元素光谱指纹的由来。与之相关但不同的是光电效应：当 \(h\nu\) 超过束缚能时，光能从固体中打出电子。

实验测的是波长，所以实用形式很重要：

\[
E = \frac{hc}{\lambda},
\qquad
E\,[\mathrm{eV}] \approx \frac{1240}{\lambda\,[\mathrm{nm}]}.
\tag{5}
\]

氢的光谱系按落点分：落到 \(n = 1\) 发出紫外（Lyman 系），落到 \(n = 2\) 发出主要在可见光与近紫外的光（Balmer 系），落到 \(n = 3\) 发出红外（Paschen 系）。

??? example "数值示例：Lyman-\(\alpha\) 线"

    \(n = 2 \to 1\) 的跃迁：

    \[
    h\nu = E_2 - E_1
    = 13.6\,\mathrm{eV}\left(1 - \frac{1}{4}\right)
    = 10.2\ \mathrm{eV},
    \]

    \[
    \lambda = \frac{hc}{h\nu}
    = \frac{1240}{10.2}\ \mathrm{nm}
    \approx 121.6\ \mathrm{nm},
    \]

    深紫外——Lyman 系的第一条谱线。

## 5. 自旋：一种独立自成的量子态

如果状态只有"装得下"的图案，清单到此为止。但 Stern 和 Gerlach（1922）让一束银原子穿过磁铁，看到它恰好裂成*两*束：电子携带一种内禀角动量——**自旋**——自旋 1/2 粒子沿任一选定测量轴的自旋投影只有两个可能结果；质子同样携带自旋。

*斯特恩–格拉赫实验：一束原子穿过非均匀磁铁，落在恰好两个斑点上，对应两个可能的自旋投影。（示意，非按比例。）*

有一点必须直说：自旋**不**由第 3 节的"装得下"论证推出。它是粒子的额外内禀属性，由实验发现，作为一类新的量子态加入量子力学。对本网站重要的是：自旋存在；每个自旋都是一块小磁铁；两块磁铁平行与反平行时能量不同。对氢而言，这种磁相互作用把基态劈成两条贴得很近的阶梯——下一篇文章讨论的单态与三重态（两块小磁铁的图景只是示意，不是固定的经典排布）——二者之间的跃迁放出 \(21\ \mathrm{cm}\) 谱线。
