# 振荡、波与共振

*本页介绍简谐运动、行波与共振——全站使用的基本语言。*

## 1. 简谐运动

最简单的简谐振动模型之一是弹簧—小球系统。回复力与位移成正比：

\[
F = -kx.
\tag{1}
\]

这里 \(k\) 是**劲度系数**——弹簧的刚度，单位是牛顿每米。（先记下一个记号提醒：等波出现之后，同一个字母 \(k\) 将表示*波数*；上下文会把两者区分开。）牛顿第二定律，\(\ddot{x} = F/m\)，化为

\[
\ddot{x} = -\frac{k}{m}\,x.
\tag{2}
\]

解是正弦波——这正是**简谐运动**（SHM）的定义性特征：

\[
\boxed{x(t) = A\cos(\omega t + \varphi_0),
\qquad
\omega = \sqrt{\frac{k}{m}}}
\tag{3}
\]

\(A\) 是振幅，\(\varphi_0\) 是初相位，\(\omega = 2\pi f\) 是角频率。频率只由弹簧与质量决定——与振幅无关——总能量守恒：

\[
E = \tfrac12 kx^2 + \tfrac12 mv^2 = \tfrac12 kA^2.
\tag{4}
\]

方程 (2) 有一个简单的性质：*两次求导让函数回到自己*，只差一个常数。正弦和余弦都满足：

\[
\frac{d^2}{dt^2}\sin\omega t = -\omega^2\sin\omega t,
\qquad
\frac{d^2}{dt^2}\cos\omega t = -\omega^2\cos\omega t.
\tag{5}
\]

复指数也满足——由欧拉公式 \(e^{i\theta} = \cos\theta + i\sin\theta\)（其中 \(i^2 = -1\)）：

\[
\frac{d^2}{dt^2}\,e^{i\omega t}
= (i\omega)^2 e^{i\omega t}
= -\omega^2 e^{i\omega t}.
\tag{6}
\]

指数形式是单位圆上转动的点，它的实部和虚部就是 \(\cos\omega t\) 与 \(\sin\omega t\)。任意两个独立解的线性组合仍是解，所以通解带两个常数，由初始位置和初始速度确定：

\[
x(t) = A\cos\omega t + B\sin\omega t
= \operatorname{Re}\!\left[C e^{i\omega t}\right].
\tag{7}
\]

小角度单摆也近似满足简谐运动方程。取弧长位移 \(x = L\theta\)，回复力为 \(F = -mg\sin\theta \approx -mg\,\theta = -(mg/L)\,x\)——正是方程 (1) 取 \(k \to mg/L\) 的形式：

\[
\omega = \sqrt{\frac{g}{L}},
\qquad
T = \frac{2\pi}{\omega} = 2\pi\sqrt{\frac{L}{g}},
\qquad
f = \frac{1}{T}.
\tag{8}
\]

??? derivation "单摆的小角近似"

    小角度下（弧度制），\(\sin\theta \approx \theta\)。取 \(x = L\theta\)：

    \[
    F = -mg\sin\theta \approx -mg\,\theta = -\frac{mg}{L}\,x,
    \]

    这正是方程 (1) 取 \(k = mg/L\) 的形式。于是

    \[
    \omega = \sqrt{\frac{k}{m}} = \sqrt{\frac{g}{L}},
    \qquad
    T = \frac{2\pi}{\omega} = 2\pi\sqrt{\frac{L}{g}}.
    \]

**相位**标定振荡处于周期中的哪个位置，\(\varphi(t) = \omega t + \varphi_0\)；两个振荡器的相位差就是时间差：

\[
\Delta t = \frac{\Delta\varphi}{2\pi f}.
\tag{9}
\]

两个 \(1\ \mathrm{Hz}\) 的摆，一个超前四分之一周期（\(\Delta\varphi = \pi/2\)），相差 \(0.25\ \mathrm{s}\)。

## 2. 波：会传播的振荡

振荡不必留在原地。绳上的波，冻结在某一瞬间：

\[
y(x) = A\sin(kx),
\qquad
k = \frac{2\pi}{\lambda},
\tag{10}
\]

其中 \(A\) 是振幅，\(\lambda\) 是波长，\(k\) 是波数（每米的相位弧度数）。时间流动时，图案滑动：

\[
y(x,t) = A\sin(kx - \omega t),
\qquad
\omega = 2\pi f.
\tag{11}
\]

图案每个周期前进一个波长，所以

\[
v = \frac{\lambda}{T} = \lambda f = \frac{\omega}{k}.
\tag{12}
\]

绳波例子：\(\lambda = 0.5\ \mathrm{m}\)，\(f = 2\ \mathrm{Hz}\) \(\Rightarrow\) \(v = 1\ \mathrm{m/s}\)。波的每个点都携带相位 \(\varphi = kx - \omega t\)：行波是一台行走的时钟，波峰以每秒 \(f\) 次的频率扫过固定的观察者。

*摩擦一圈圈地抽走能量，振幅随之衰减。没人推的话，任何真实振荡器最终都会停下来。*

在本节使用的简单**线性黏性阻尼模型**里，阻力与速度成正比、方向与速度相反——这是摩擦最简单的诚实模型，足以抓住物理。把它加进弹簧的牛顿定律，得到

\[
m\ddot{x} + b\dot{x} + kx = 0,
\tag{13}
\]

其中 \(-b\dot{x}\) 项是摩擦力。我们不详细解这个方程——上面的图是它预言行为的*示意草图*，不是精确解——但方程本身值得读一读：每一项都有清晰的物理职责，而摩擦项是那个不断做减法的。

现在推秋千。外部周期性驱动力一个周期接一个周期地把能量喂回来：

\[
m\ddot{x} + b\dot{x} + kx = F_0\cos(\omega t).
\tag{14}
\]

结果尖锐地取决于驱动频率 \(\omega\)。按秋千自己的节奏推，它每推一下都更高；节奏不对，你的推力一半时间在对抗运动、自我抵消。在固有频率

\[
\omega_0 = \sqrt{\frac{k}{m}}
\]

附近，振荡器响应剧烈——**共振**——摩擦越小，响应越尖锐（阻尼很小时峰值基本就在 \(\omega_0\)；摩擦变大时峰会变宽并略微偏移，所以没有任何单一数字能描述所有情形）。

*共振曲线：阻尼小则峰尖，阻尼大则峰宽。想象推秋千——同样的推力，按秋千自己的节奏推，一圈圈地积累高度；节奏不对，就自己抵消自己。*

共振解释了为什么秋千要按自己的节奏推才升高，为什么歌剧演员能震碎酒杯，以及——对本网站最重要的——为什么微波腔（[2.3 页](../hydrogen-frequency-standard/from-a-quiet-atom-to-a-ticking-clock.md)）只响应它被加工成的那个频率，为什么原子能在其跃迁频率处被驱动（[2.2–2.3 页](../hydrogen-frequency-standard/spins-in-a-magnetic-field.md)）。共振系统就是一个频率滤波器。

## 4. 光：本身即波

光也是一种振荡，

\[
c = \lambda f,
\tag{15}
\]

其中 \(c = 299\,792\,458\ \mathrm{m/s}\) 是**真空中**的光速，一个精确的定义值。但这里必须放一句提醒，因为这是一个常见的错误捷径：光的波动性**并不**由弹簧推导而来。它由麦克斯韦方程组与实验确立；简谐运动提供的只是双方共用的语言——振幅、频率、相位。可以搬走的是词汇，不是推导。

??? example "数值示例"

    绿光，\(\lambda = 500\ \mathrm{nm}\)：

    \[
    f = \frac{c}{\lambda} = \frac{3.0\times10^{8}}{5.0\times10^{-7}} = 6\times10^{14}\ \mathrm{Hz}.
    \]

    Wi-Fi，\(f = 2.4\ \mathrm{GHz}\)：

    \[
    \lambda = \frac{c}{f} = \frac{2.998\times10^{8}}{2.4\times10^{9}} \approx 12.5\ \mathrm{cm}.
    \]

同一个家族，同一个方程：无线电（米）、微波（厘米）、可见光（\(400\)–\(700\ \mathrm{nm}\)），以及伽马射线——家族中能量最高、波长最短的成员。本站的三个项目都住在这张地图上——氢钟的微波音符、用可见光与紫外探测的半导体、来自太空的伽马射线。
