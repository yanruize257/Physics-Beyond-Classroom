# 伽马射线的产生与相互作用

*本页介绍伽马射线的主要产生机制及其与物质的相互作用。*

## 1. 什么是伽马射线

伽马射线是能量在约 \(100\ \mathrm{keV}\) 以上的光子——这是一个约定边界而非严格界限，因为 X 射线与伽马射线的能量范围有重叠——位于频谱顶端，远在[基础篇](../foundations/oscillations-waves-and-resonance.md)的可见光之上：

\[
E = h\nu \gtrsim 10^5\ \mathrm{eV},
\qquad
\lambda = \frac{hc}{E} \lesssim 10^{-11}\ \mathrm{m}.
\tag{1}
\]

在这个能量段，光子与物质通过单个原子的吸收和散射相互作用，而不是通过使镜子起作用的表面集体响应——所以镜子和透镜对伽马射线望远镜没有用处。能量尺度也匹配核跃迁而非电子跃迁：

\[
E_{\text{电子}} \sim 1\ \mathrm{eV},
\qquad
E_{\text{核}} \sim 10^5\text{–}10^7\ \mathrm{eV}.
\tag{2}
\]

伽马射线由原子核的跃迁、粒子碰撞或湮灭产生——这些过程的能量比化学高约十万倍。

## 2. 它们从哪来

天空中的伽马射线源是已知最暴烈的地方：脉冲星——自旋的中子星，其磁场把粒子加速到极端能量；超新星遗迹——激波把粒子推过数光年；活动星系核——物质坠入十亿太阳质量的黑洞，能量灌进喷流；以及伽马暴——大爆炸以来最亮的爆炸。它们送来的光子由几种*不同的*机制产生：

- **同步辐射**——在磁场中打转的相对论电子辐射光子，光子能量随场强与电子能量升高。
- **逆康普顿散射**——相对论电子与低能光子（星光、红外、宇宙微波背景）相撞，把它踢到伽马能段。值得记住的画面：一个快速网球（电子）撞上一个慢速网球（光子），把后者打飞并带走前者的很大一部分能量——这是简化类比，实际上粒子通过电磁相互作用交换能量与方向，但它抓住了能量传递的方向。
- **π 介子衰变**——宇宙线质子与星际气体碰撞产生中性 π 介子，它几乎立刻衰变成两个伽马光子：

\[
\pi^0 \to \gamma + \gamma.
\tag{3}
\]

- **湮灭**——正反物质湮灭成光子：

\[
e^+ + e^- \to \gamma + \gamma.
\tag{4}
\]

一个具体的源往往混合几种机制，哪种占主导会在能谱上留下自己的签名。伽马射线沿直线飞行，不被星系磁场偏折，指向自己的来源。

## 3. 为什么普通光学方法通常失效

可见光能被镜子反射，是因为金属中的传导电子能跟上振荡的电场。伽马射线的场振荡太快，光子能量太高：它不会被表面相干地偏转，而是压倒性地被单个原子吸收或散射。因此普通的镜子与透镜不适用于常规伽马射线观测——掠入射反射和晶体衍射等特殊技术存在，但只适用于有限低能情形——

\[
\lambda_{\gamma} \lesssim a_{\text{原子}},
\tag{5}
\]

但这句话需要精确：反射并非在所有伽马波长上都字面地被禁止——掠入射反射在 X 射线能段仍然有效，低能特殊情形下也有人使用晶体衍射——只是这两种技术都造不出宽视场的伽马成像仪。实践中，伽马射线靠*把能量交给粒子*来宣告自己。三种机制随能量升高依次占优（确切范围取决于材料）：

- **光电效应**——光子打出束缚电子；约 \(100\ \mathrm{keV}\) 以下占优。
- **康普顿散射**——光子撞开松散束缚的电子，能量减小后离开；中段占优。
- **对产生**——越过阈值后，光子直接转化为物质。

## 4. 对产生：光变成物质

在原子核附近（需要它吸收反冲动量），能量足够的光子能转化成一个电子和一个正电子：

*对产生：光子在原子核附近转化为电子–正电子对，原子核吸收反冲动量。（示意，非按比例。）*

\[
\gamma \to e^- + e^+.
\tag{6}
\]

对这一核场机制——也就是 LAT 这类望远镜使用的机制——能量守恒给出阈值，动量守恒由原子核处理，而下面的数值是忽略原子核那份微小反冲能量的近似：两个粒子各需付出静能 \(m_e c^2\)，所以

\[
\boxed{E_{\text{阈值}} \approx 2m_e c^2 = 1.022\ \mathrm{MeV}}
\tag{7}
\]

低于 \(1.022\ \mathrm{MeV}\)，单个光子在原子核附近根本无从转化。高于它，对产生的概率随光子能量与材料的原子序数增长——LAT 的转化器用钨正是为此——但对产生是否压过光电吸收与康普顿散射，取决于能量与材料两者；这种主导性是探测器转化器选择的性质，而不是频谱的普适规律。对产生也不是建造伽马射线望远镜的唯一途径：**康普顿望远镜**（工作于约几百 keV 到几 MeV，从下方跨越阈值）测量光子撞出的电子，由反冲推断光子的方向与能量。Fermi-LAT 从几十 MeV 以上工作，以对产生为原理，正是因为这一机制在它的能段占主导——*让伽马射线变成粒子，再测量粒子。*

??? derivation "阈值推导"

    能量守恒给出下界，动量守恒解释为什么需要原子核。最便宜的产物是一对没有剩余运动的粒子，花费静能 \(2m_e c^2\)。在核场过程中，邻近原子核吸收反冲动量；忽略它那份微小的反冲能量后，光子至少要携带

    \[
    E_{\text{阈值}} \approx 2m_e c^2 = 2\times0.511\ \mathrm{MeV} = 1.022\ \mathrm{MeV},
    \]

    这是一个好于百分之一的近似。低于此能量，过程根本无法发生。原子核必不可少：单个光子在守恒能量*与*动量的前提下变成一对粒子，必须有第三者拿走动量，而重核拿走动量却几乎不拿能量，正是理想的第三者。
